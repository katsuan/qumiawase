# くみあわせ（QumiAwase）

トーナメントも総当たりも、すぐできる。チームを入れるだけで、組み合わせと日程を作り、結果から勝ち上がりと順位表を出します。
サッカー・フットサルのほか、どの競技でも使えます。サーバーは使わず、大会はこの端末の中だけに残します。

https://katsuan.github.io/qumiawase/ （確認中のため、検索には出しません）

## できること

- **チーム**：名前と色（さくせん盤・ろくがと同じ8色とカスタム）。並べかえ・シャッフル・まとめて入れる（1行に1チーム）。2〜32チーム
- **形**
  - トーナメント：上から順にシード。2のべき乗に足りないときは、上のシードが不戦勝。3位決定戦（する・しない）
  - 総当たり：1回・2回（ホーム・アウェイ）。円形の回し方で、ホームの数がかたよらないように
  - グループ → 決勝トーナメント：グループの数・上がる数。グループ分けは行って帰ってくる順。決勝トーナメントのはじめは、ちがうグループどうし
- **日程（なくてもOK）**：日にち・はじまりの時刻・コートの数・1試合の時間から、試合ごとの時刻とコートを割りふる。同じ時間に同じチームは入れず、なるべく続けて出ないように
- **結果**：点は − 数 ＋。トーナメントで同点のときは PK も。勝ったほうが次へ。総当たりは順位表（勝ち点 勝3・分1・負0。設定で変えられる。並びは 勝ち点 → 得失点差 → 総得点 → 直接対決）
- **さくせん盤・ろくがと行き来する**
  - 試合ごとの「⚽ さくせん盤で開く」：2チームの名前と色・会場・日にち・時刻を、さくせん盤の「👕 チーム・試合結果」に入れて開く（`?match=`）
  - さくせん盤で点を入れて「🏆 くみあわせに結果を戻す」：点と PK が、くみあわせのその試合に入る（同じ端末は localStorage の `qumiawase:inbox` とリンク、ちがう端末は「🔗 結果のリンク」を送る。`?result=`）
  - 試合ごとの「📹 ろくがで撮る」：2チームの名前と色を、ろくがに入れて開く（`?match=`）
- **送る・保存する**：「カードで送る」（おくるんのお知らせカード。組み合わせ・結果・順位を文で）・「📷 画像で保存」（トーナメント表・順位表・試合の一覧）・「🔗 見る人用のリンク」（大会の中身を URL にのせる。開いた人は見るだけで、この端末に保存すると結果を入れられる）
- **大会**：この端末に 30 件まで（新しく作る・複製・消す。名前はいつでも変えられる）

## ファイル

ファイルの名前は Q のツール共通の決まり（q-oqrn の docs/structure.md）にそろえている。

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（部品は Q キットの `ui.css`） |
| `app.js` | 入口：画面を作り、ボタン・入力を受け、部品をつなぐ |
| `js/settings.js` | ツールの名前・色・数の上限。**名前を変えるときは、まずここ**（ほかに `index.html` の meta・`manifest.webmanifest`・この README・`tools/icon.py`） |
| `js/pairing.js` | 組み合わせを作る（トーナメント・総当たり・グループ）と、日程の割りふり |
| `js/stats.js` | 結果から勝ち負け・順位表・勝ち上がり・優勝 |
| `js/store.js` | 大会をこの端末に残す・読む（形を確かめる） |
| `js/link.js` | 見る人用のリンク・さくせん盤やろくがで開くリンク・結果を戻すリンク |
| `js/card.js` | おくるんのカードの中身と、試合や順位の言い方 |
| `js/image.js` | 「📷 画像で保存」の画像 |
| `sw.js`・`manifest.webmanifest` | 電波がないときに開く仕組みと、ホーム画面に置くときの設定 |
| `test/` | テスト（`node --test test/`。さくせん盤・ろくがとの受けわたしは、となりの q-saqsen・q-roqga があるときだけ） |
| `tools/icon.py` | アイコン・ロゴ・OGP を作る（おくるんの tools/brandkit.py を使う） |

公開前に `python3 ../q-oqrn/tools/qstamp.py index.html`（読み込む CSS・JS に版の番号）と `node ../q-oqrn/tools/qtest/check-code.mjs .`。
