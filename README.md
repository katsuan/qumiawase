# くみあわせ（QumiAwase）

トーナメントも総当たりも、すぐできる。チームを入れるだけで、組み合わせと日程を作り、結果から勝ち上がりと順位表を出します。
サッカー・フットサルのほか、どの競技でも使えます。サーバーは使わず、大会はこの端末の中だけに残します。

https://katsuan.github.io/qumiawase/ （確認中のため、検索には出しません）

## できること

- **ページのタブ**：「⚙️ 準備」（大会・チーム・形と試合の種類（1つの枠。形 → 「📊 総当たりの決まり」（回数・勝ち点・PK・順位の決め方。勝ち点と順位の決め方はたためる）と「🗺️ トーナメントの決まり」（3位決定戦）の箱。グループのときは両方で、名前は「グループの総当たり」「決勝トーナメント」 → 種類のタブ → 見こみ。種類は時間と日程のとなり）・時間と日程・審判）と「📋 試合」。試合のページは、見せる中身ごとに「📋 試合と結果」「📊 順位表」「🗺️ トーナメント」のタブ（その形にあるものだけ）。送る・保存はどのタブでも下に。準備のいちばん下の「📋 試合へ（N試合）」で試合へ。結果が入りはじめた大会は試合から開く。見る人用のリンクは試合だけ
- **試合の種類**：サッカー 8人制・11人制・フットサル・ミニバス・バレー・卓球やテニスのタブを押すと、1試合の時間・空き時間・勝ち点・3位決定戦の初期設定が入る（目安。手で変えると「自分で決める」に。`js/settings.js` の `PRESETS`）
- **チーム**：名前と色（さくせん盤・ろくがと同じ8色とカスタム）。並べかえ（つまみ ⠿ を押したまま上下に。↑↓ キーでも）・シャッフル・まとめて入れる（1行に1チーム）。2〜32チーム
- **形**
  - トーナメント：上から順にシード。2のべき乗に足りないときは、上のシードが不戦勝。3位決定戦（する・しない）
  - 総当たり：1回・2回（ホーム・アウェイ）。円形の回し方で、ホームの数がかたよらないように
  - グループ → 決勝トーナメント：グループの数・上がる数。グループ分けは行って帰ってくる順。決勝トーナメントは、同じグループのチームがなるべく遅い回まで当たらない並び（1位と2位は決勝まで。4グループ×2なら A1-C2・D1-B2・B1-D2・C1-A2、2グループなら A1-B2・B1-A2）
- **時間と日程**：コートの数・1試合の時間（1分ずつ。数字を押して直接も入れられる。空き時間も同じ）・同じチームの連続試合（避ける／続けてもよい）。避けるときは「試合の間の空き時間」をあけて組み、足りないときはコートを空けて待つ（バッファ）。トーナメントの次の回は前の回が終わってから。「時刻を入れる」と日にち・はじまり・会場も
- **時刻を直す・遅れ**（時刻を入れているとき）：入力中のカードの「🕘 時刻・コート」で、その試合だけ手で決める（✏️。遅れはのせない。「自動にもどす」で戻す。同じコートで時間が重なると ⚠️重なり）。試合の表の上の「⏱ 遅れ」で、次の試合（まだの、いちばん早い試合）から、まだの試合の時刻をまとめて ±5分ずつ後ろへ（⏱+10分 の印。どこからずらしたかを覚えるので、あとで結果を入れても戻らない。「なくす」で元に）。組み合わせが変わると、手で決めた時刻は消える。運営（準備を変えられる人）だけ
- **見こみ**：試合の数・1チームの最多の試合の数・かかる時間（時刻を入れていれば終わりの時刻も）を、形の下にいつも出す
- **試合表**：順番（時刻か何試合目）・コート別・チーム別。順番の見方は時刻（なければ節・回）ごとにたためる（はじめは、ぜんぶ終わったまとまりだけたたむ。押した開け閉めは覚える）。次の試合（結果のまだの、いちばん早い試合）は「▶ 次の試合」で目立たせ、「⬇ 次の試合へ」でそこまで動く。終わった試合は「✓ 終わり」で小さく。カードはふだん点だけで、押した1枚だけが入力中になり、− ＋・PK・審判・「結果を消す」・さくせん盤やろくが（まだの試合）が出る（もう一度押すか、ほかのカードを押すと閉じる）。チーム別で選んだチームは、順位表・トーナメント表でも色をつける。トーナメント表がはみ出すときは、表だけ横にずらせる（案内も出す）。トーナメント表の試合の箱の上に、時刻とコート（時刻がなければ何試合目）。3位決定戦は決勝の列の下（どの列にも同じ高さの下の段をつけて、線の高さをそろえる）。優勝・準優勝・3位は1行ずつ。トーナメント表の試合（2チームが決まったもの）も、押すと総当たり表と同じ点を入れる窓が開く（同点なら PK も）。チーム別には、そのチームが審判をする試合も「🟨 審判」の行で試合のあいだに入れ、数も出す。チーム別は、トーナメントを勝ち進んだとき（勝てば決勝まで・負けたら3位決定戦）・グループを1位で上がったときの決勝トーナメントから決勝までも時刻つきで。最多の試合の数も出す。くろのすにも、まだ相手が決まらない試合を「vs 準決勝 2の勝者」のように入れる
- **審判**：試合ごとに「🟨 審判」を、その試合に出ない・同じ時間にほかのコートで試合のないチームから選ぶ（いなければ −。当日の入れかえ用。点の行の下に、ラベルとチーム名をまん中そろえで出す。選ぶ欄は入力中のカードだけ）。準備の「🟨 審判」の枠の「🟨 審判を自動で入れる」で（まだ1つもないときは、試合の画面に「準備で自動で入れられます」の案内）、まだの試合（出るチームが決まっているもの。トーナメントの先は結果が入ってからもう一度）に、審判の数がそろうように（前後の空き時間に試合があるチームはなるべく避ける）。組み合わせが変わると消える。勝ち上がりで出ることになったら ⚠️。大会のまとめ・見る人用のリンクにも
- **総当たり表**：順位表の下に、チームどうしのマス目の表（左のチームから見た ○ 2-1・● 0-1・△ 1-1。まだの試合は時刻か何試合目。2回総当たりは1マスに2つ）。マスを押すと、その場で − 数 ＋ の窓が開いて点を入れられる（入れるとすぐ順位表・総当たり表・試合の表に出る。「結果を消す」は元に戻せる。「📋 試合の表で見る」でその試合へ動いて光る。見るだけの人は試合の表へ）。チーム名の列は横にずらしても残る
- **結果**：点は − 数 ＋。トーナメントで同点のときは PK も（PK で決める試合の同点は、PK が決まるまで「終わり」にしない。次の試合の印・終わった数・グループの順位もそれまで動かない）。勝ったほうが次へ。総当たりは順位表（グループのときは、組ごとに順位表と総当たり表を1つの箱にまとめる。勝ち点 勝3・分1・負0。設定で変えられる。並びは 勝ち点 → 得失点差 → 総得点 → 直接対決 がはじめ。「順位の決め方」で勝ち点のあとの3つを ↑↓ で並べかえられる。直接対決は、そこまで同じ並びのチームどうしの試合だけで 勝ち点 → 得失点差 → 総得点）。勝ち点の「同点なら PK をする」で、総当たりでも同点のとき PK を入れ、PK勝ち・PK負けの勝ち点（はじめは2・1）にできる（引き分けはなくなるので、引き分けの勝ち点の欄と順位表の「分」は出さない。PK を入れるまでその試合は数えない。順位表に PK勝・PK負の列、総当たり表に「PK4-3」。PK の点は得失点に入れない）
- **さくせん盤・ろくがと行き来する**（試合のカードを押して入力中にすると出る。終わった試合には出さない）
  - 試合ごとの「⚽ さくせん盤で開く」：2チームの名前と色・会場・日にち・時刻を、さくせん盤の「👕 チーム・試合結果」に入れて開く（`?match=`）
  - さくせん盤で点を入れて「🏆 くみあわせに結果を戻す」：点と PK が、くみあわせのその試合に入る（同じ端末は localStorage の `qumiawase:inbox` とリンク、ちがう端末は「🔗 結果のリンク」を送る。`?result=`）
  - 試合ごとの「📹 ろくがで撮る」：2チームの名前と色を、ろくがに入れて開く（`?match=`）
- **くろのす（カウントダウン）**：時刻を入れていれば、チーム別の試合（勝ち進みもふくむ）や大会（はじまり・決勝）の「あと◯分」を、くろのすのボードで開く（`https://katsuan.github.io/countdown/?z=`。12件まで）。チーム別の行の色は相手のチームの色（白・黄は読める濃さに）。ボードには「🏆 大会を見る」（見る人用のリンク。ボード全体で1つ）も付ける
- **📜 大会要項**：準備の「📜 大会要項」に、ルール・持ち物・雨天のときなどの長い文（5000字まで・改行あり）。試合のページの上に「📜 大会要項」としてたたんで出す（https:// はリンクに）。みんなで入れる大会なら見る人にも出る（運営だけが書ける）。大会のまとめ（印刷・文）にも入る。見る人用のリンクには入れない（長くなるため）
- **大会のまとめ**：名前・日程・チーム・順位表・トーナメント表・試合の表を、印刷・PDF に保存／文でコピー
- **送る・保存する**：「カードで送る」（おくるんのお知らせカード。組み合わせ・結果・順位を文で）・「📷 画像で保存」（トーナメント表・順位表・試合の一覧）・「🔗 見る人用のリンク」（大会の中身を URL にのせる。開いた人は見るだけで、この端末に保存すると結果を入れられる）
- **📡 みんなで入れる**（くらぶボット。つながなくても、これまでどおり端末の中だけで使える）：送る・保存するの下の「📡 みんなで入れる」で、くらぶボット（使う人の GAS。q-qlove-bot の「🏆 大会」）の URL を入れ、「この大会をみんなで入れる」で、運営の合言葉（ボットを作った人がスクリプト プロパティ `TOURNAMENT_ADMIN_KEY` に書いたもの）と入力の合言葉（コートの人に口で伝える）を入れて「この大会をみんなで入れる」。合言葉の欄は窓でなくページの中に置く（iPhone で下から出す窓の入力欄は、キーボードと重なったり、続けて出すと入れなかったりするため）。「🔗 共有リンク」（`?live=番号&bot=ボットの URL`。合言葉は入らない）を開いた人は見るだけで、「✏️ 点を入れる」で合言葉を入れると点と審判を入れられる（運営の合言葉なら準備も）。点は1試合ずつ送り、ほかの人の点は「🔄 更新」を押したときだけ読む（GAS をあまり呼ばないため。はじめて共有リンクを開いたときだけは1回読む）。電波がないときは端末にためて、つながったら送る。さくせん盤から「結果を戻す」で届いた点も送る（そのタブが見るだけなら、端末にためて、お知らせの「✏️ 合言葉を入れて送る」から合言葉を入れると送る）。合言葉は送らず（入力は PBKDF2・運営は SHA-256 にしたもの）、URL にも端末にも残さない（そのタブの sessionStorage だけ）。画面は `js/live-ui.js`、中身は `js/live.js`
- **大会**：この端末に 30 件まで。準備のいちばん上の1行に名前（押すと名前を変える）と「…」（大会の一覧から切りかえる・新しく作る・名前を変える・複製・消す。消したあとは「元に戻す」）

## ファイル

ファイルの名前は Q のツール共通の決まり（q-oqrn の docs/structure.md）にそろえている。

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（部品は Q キットの `ui.css`） |
| `app.js` | 入口：部品をつなぎ、描きなおしの順番を決める。ページのタブ・さくせん盤から戻ってきた結果・起動 |
| `js/state.js` | いまの大会（端末の大会・見る人用のリンクの大会）・役割（見るだけ／入力／運営）・ページと見方・残す・変える（元に戻す）・計算をまとめて返す。部品から上の描きなおしは `ui` を通して呼ぶ |
| `js/dom.js` | 画面の小さな道具（`$`・`esc`・トースト・季節の絵文字・− 数 ＋ の欄） |
| `js/prep-event.js` | 準備の「大会」：名前・「…」（切りかえ・新しく作る・複製・消す）・見る人用のリンクの大会を保存 |
| `js/prep-teams.js` | 準備の「チーム」：名前と色・並べかえ・足す・消す・シャッフル・まとめて入れる |
| `js/prep-format.js` | 準備の「形と決まり」「時間と日程」「大会要項」と、見こみ（試合の数・かかる時間） |
| `js/play-matches.js` | 試合の表：カード・入力中の試合・審判・時刻を手で直す・⏱ 遅れ・時刻ごとのまとまり・コート別 |
| `js/play-tables.js` | トーナメント表・順位表・総当たり表と、そこから開く「点を入れる」窓 |
| `js/play-team.js` | 試合の表の「チーム別」（勝ち進み・審判をする試合）と、くろのすのカウントダウン |
| `js/play-score.js` | 点を入れる・消す、点の − 数 ＋、終わったか・PK・いつ、試合の表のその試合へ動く |
| `js/share-ui.js` | 送る・保存：おくるんのカード・📷 画像・🔗 見る人用のリンク・📄 大会のまとめ（印刷・PDF・文） |
| `js/live-ui.js` | 「📡 みんなで入れる」の画面（のせる・合言葉・送る・🔄 更新・共有リンク・つなぐのをやめる） |
| `js/settings.js` | ツールの名前・色・数の上限。**名前を変えるときは、まずここ**（ほかに `index.html` の meta・`manifest.webmanifest`・この README・`tools/icon.py`） |
| `js/pairing.js` | 組み合わせを作る（トーナメント・総当たり・グループ）と、時間の割りふり（コート・空き時間） |
| `js/stats.js` | 結果から勝ち負け・順位表・勝ち上がり・優勝。見こみ（試合の数・時間） |
| `js/store.js` | 大会をこの端末に残す・読む（形を確かめる） |
| `js/live.js` | みんなで入れる（くらぶボットの「🏆 大会」。画面には触らない）：共有リンク・合言葉の key・送るのを待っているもの・ボットの中身との合わせかた |
| `js/link.js` | 見る人用のリンク・さくせん盤やろくがで開くリンク・結果を戻すリンク・くろのすのボード |
| `js/card.js` | おくるんのカードの中身・大会のまとめの文と、試合や順位の言い方 |
| `js/image.js` | 「📷 画像で保存」の画像 |
| `sw.js`・`manifest.webmanifest` | 電波がないときに開く仕組みと、ホーム画面に置くときの設定 |
| `test/` | テスト（`node --test test/`。みんなで入れるの中身は `test/live.test.mjs`。さくせん盤・ろくがとの受けわたしは、となりの q-saqsen・q-roqga があるときだけ） |
| `tools/icon.py` | アイコン・ロゴ・OGP を作る（おくるんの tools/brandkit.py を使う） |

公開前に `python3 ../q-oqrn/tools/qstamp.py index.html`（読み込む CSS・JS に版の番号）と `node ../q-oqrn/tools/qtest/check-code.mjs .`。
